CG Unpacker v1.5  —— 使用说明
==================================

一、怎么打开
  完整解压 Windows 版 ZIP，双击 CG Unpacker.exe，保持 _internal 文件夹与它同级。
  · 把资源包拖进窗口 → 只会打开、列出里面的文件，不会自动全解
  · 也可以点「打开文件」，选择要解包的资源包，先预览里面的文件
  · 拖入整个游戏文件夹可扫描资源包。也可以把文件夹拖到 exe 或快捷方式上

二、怎么挑图（重点）
  1. 打开后左列是包内所有文件，点一条 → 右边立刻预览
  2. 想解哪张就选哪张：
       单击         选中一条
       Ctrl + 单击  一条一条加选
       Shift + 单击 连续选一段
  3. 选好后点「解包选中 (N)」，只解选中的那几张
  4. 直接双击某一行 = 只解这一张
  5. 右键菜单也有「解包这一张 / 解包选中的 N 张」
  6. 「全部解包」是整包，慎点

三、保存位置
  解包按钮下方会显示完整保存路径，点「更改目录…」可换默认位置。
  勾着「解包时问保存位置」时，每次解包前可以另选目录，选好后路径栏会更新。
  取消勾选后，单个归档会存到默认目录下的同名子文件夹，路径栏会直接显示这个子文件夹。

四、扫描游戏文件夹
  拖入文件夹，或点「扫描文件夹」（Ctrl+B）。程序会检查目录和子文件夹里的文件。
  扫描结果按能读取包内目录的资源包计数，列出每个包的路径、格式和条目数。
  双击一个包可进入预览，点主窗口的「扫描结果」可返回列表换包。
  按住 Ctrl 或 Shift 多选后点「解包选中」，或点「解包全部」导出列表中的所有包。
  窗口会显示批量保存路径，每个包各用一个子文件夹，同批重名的包会自动编号。

五、支持的格式
  归档：AFA(AliceSoft v1/v2/v3)、ALD(AliceSoft)、XP3（含 EXE 内嵌）、ZIP、YPF、NPA、PFS、RealLive G00
  图片：QNT、DCF、AJP、G00、TLG5、部分 TLG6，以及 PNG/JPG/BMP/WebP/GIF

六、常见问题
  · 界面模糊：v1.4 起已经做了 DPI 感知，系统缩放 125%/150%/200% 下都是清晰的
  · 拖进去没反应：点「扫描文件夹」选择游戏目录，也可以按 Ctrl+B
  · 提示「识别不了这个格式」：加密包或者还没支持的引擎
  · 解出来空白/花屏：少数游戏对图片二次加密了
  · 会改游戏文件吗：不会，只读

七、命令行（可选）
  在 PowerShell 运行 & ".\CG Unpacker.exe" "D:\game\CG.afa" 可直接打开列表
  python -m unpacker.cli 包.afa       ← 命令行直接解

八、检查更新
  点击主窗口的「检查更新」，或从「帮助」菜单进入。发现新版后可查看说明、下载并重启安装。
  更新时会保留当前的设置和导出目录。

源码与说明见 https://github.com/SatouTO/CG-Unpacker
